Black Hole Screensaver

Real-physics Schwarzschild black-hole OpenGL screensaver for Linux.
项目主页：github.com/Wian1977/blackholescreensaver

apt (Debian / Ubuntu / Linux Mint)

echo "deb [trusted=yes] https://wian1977.github.io/blackholescreensaver/ ./" | sudo tee /etc/apt/sources.list.d/blackhole.list
sudo apt update && sudo apt install blackhole-screensaver

dnf / yum (Fedora / RHEL)

sudo tee /etc/yum.repos.d/blackhole.repo <<'EOF'
[blackhole]
name=Black Hole Screensaver
baseurl=https://wian1977.github.io/blackholescreensaver/rpm/
enabled=1
gpgcheck=0
EOF
sudo dnf install blackhole-screensaver

直接下载 / Direct downloads

  • GitHub Releases v1.1.0 — .deb / .rpm / AppImage
  • BlackHoleScreensaver-1.1.0-x86_64.AppImage — chmod +x 后直接运行（--windowed 开窗口预览）

其他渠道 / Other channels

  • Nix (NUR): repos.Wian1977.blackhole-screensaver
  • Homebrew: brew tap Wian1977/blackhole && brew install blackhole-screensaver
  • Arch (AUR): blackhole-screensaver

apt / RPM 仓库未做 GPG 签名，故使用 trusted / gpgcheck=0。构建由 GitHub Actions 自动生成。
