Black Hole Screensaver

把《星际穿越》里的 Gargantua 黑洞变成你的 Linux 屏保 —— 不是循环视频，而是每一帧都由 GPU 实时演算的真实物理黑洞（史瓦西度规测地线积分）。

GitHub 仓库 下载 .deb

为什么值得装

  • 真实引力透镜：光线按史瓦西度规实时测地线偏折（u'' = -u + 1.5·rs·u²）
  • 吸积盘相对论聚束（朝向侧更亮更蓝）+ 多普勒/引力红移
  • 星空被透镜成爱因斯坦环（可开关）
  • DE 无关守护进程：Cinnamon / KDE / GNOME / Xfce / MATE 锁屏或空闲时自动全屏
  • X11 与 Wayland 都安全（Wayland 下优雅出现在锁屏之下或之前）
  • 零空闲开销：平时只跑轻量守护，锁屏/空闲才拉起渲染

一条命令安装

git clone https://github.com/Wian1977/blackhole-screensaver.git
cd blackhole-screensaver
./install.sh

依赖自动检测（python3-gi, gir1.2-gtk-3.0, python3-xlib, Mesa/OpenGL）。或到 Releases 下载系统级 .deb。

支持的桌面

  • Linux Mint Cinnamon (X11) — 完整支持
  • Xfce / MATE — 完整支持
  • KDE (X11) — 守护进程自动触发
  • GNOME (X11 / Wayland) — 守护进程自动触发
  • Wayland (KDE / GNOME) — 优雅降级
